🎌 Anime Vault

Anime Vault is a modern anime discovery platform that allows users to explore, browse, and discover popular anime series and movies through an elegant and responsive interface. Built with TypeScript and modern frontend technologies, the application delivers an engaging user experience for anime enthusiasts by presenting anime information in a visually appealing and accessible way.

🌐 Live Demo: https://anime-vault-site.netlify.app/
📂 Repository: https://github.com/rkazumovi/Anime-Vault

📖 Overview

Anime Vault was developed to provide anime fans with a centralized platform for discovering anime content across different genres and formats. The application showcases highly rated anime series and movies, allowing users to easily explore titles, episode counts, ratings, and media types.

The project demonstrates modern frontend development practices, responsive design principles, and effective integration with external anime data sources.

✨ Features
🎬 Browse popular anime series and movies
⭐ View anime ratings and scores

🚀 Getting Started
Prerequisites

Make sure you have installed:

Node.js (v18 or later recommended)
npm or yarn
Git
⚙️ Installation

Clone the repository:

git clone https://github.com/rkazumovi/Anime-Vault.git

Navigate to the project directory:

cd Anime-Vault

Install dependencies:

npm install

or

yarn install
▶️ Running Locally

Start the development server:

npm run dev

or

yarn dev

Open your browser and visit:

http://localhost:3000
